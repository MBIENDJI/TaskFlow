# TaskFlow API

## Description

TaskFlow est une API REST développée avec Django et Django REST Framework pour la gestion des équipes, des projets, des tâches et des commentaires.

L'API permet de :

- Gérer les membres
- Gérer les équipes
- Gérer les projets
- Gérer les tâches
- Gérer les commentaires
- Affecter des membres à une équipe
- Assigner des tâches aux membres d'un projet

---

## Technologies utilisées

- Python
- Django
- Django REST Framework
- SQLite
